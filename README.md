# Life OS — личный Life Tracker (PWA)

## Функции
- Главная сводка по задачам, финансам, привычкам и целям.
- Календарь с маркерами задач; перетаскивание задачи на другую дату (на устройствах с drag-and-drop).
- Задачи: категории, важность, заметки, сроки, отметка выполнения и повторение (ежедневно/еженедельно/ежемесячно).
- Финансы: расходы по категориям, месячные бюджеты, остатки и аналитика расходов за неделю/месяц/год.
- Привычки: частота, ежедневная отметка, история активности и аналитика за неделю/месяц/год.
- Цели: измеримый прогресс, срок, сфера и быстрый шаг +1.
- Резервное копирование JSON: экспорт/импорт.
- Офлайн-кеширование через Service Worker; данные хранятся локально в браузере.

## Локальный запуск
В папке проекта:
```bash
python -m http.server 8000
```
Откройте http://localhost:8000. Service Worker работает на localhost и HTTPS.

## Установка
Разместите файлы на HTTPS-хостинге (GitHub Pages, Netlify или собственный сервер), откройте сайт на телефоне и выберите «Добавить на главный экран» / «Установить приложение». После первого успешного открытия ресурсы кешируются и доступны офлайн.

## Важные ограничения
- Данные не синхронизируются между устройствами. Для переноса используйте экспорт JSON на старом устройстве и импорт на новом.
- Очистка данных браузера может удалить локальные записи; делайте резервные копии.
- Напоминания пока не отправляют системные push-уведомления: поле привычки — заметка-подсказка, не будильник.
- Повторяющаяся задача создаёт следующий экземпляр после отметки выполнения.
- Drag-and-drop может быть недоступен на некоторых мобильных браузерах; в этом случае дату можно поменять через редактирование задачи.
